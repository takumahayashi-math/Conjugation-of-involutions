We examine Lemma 4.10.1 from Yokota's book "Exceptiona Lie groups" as an essentially algebraic result. We also discuss its analog for lambda and iota*lambda. 

In the sage files, the sources are included. We compute the actions as matrices with the standard basis
(xi_1,xi_2,xi_3,c_1,c_2,c_3,eta_1,eta_2,eta_3,d_1,d_2,d_3,xi,eta) of the Freudenthal vector space V(A).
To be precise, we think of c_i, d_i in C as blocks.

Following Yokota's book, we construct the translation matrix delta. We check the conjugacy result and compute the attached cocycle.
The results are appended as the result files.
